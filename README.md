A practice repository for learning Git and GitHub workflows.

## Useful Git Notes
- `git status` shows the current state of the working directory.
- `git add <file>` stages changes for the next commit.
- `git commit -m "message"` records staged changes with a message.
- Always create a branch for new work instead of committing directly to `main`.
- Write short, clear commit messages that explain *why* a change was made.
